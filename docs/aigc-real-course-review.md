前端 `D:/Java/tj-protal/src/pages/classDetails/components/ClassAbout.vue` 原先使用文本插值输出 `detail`，导致 HTML 标签原样显示。现改为 DOMPurify 3.4.17 净化后渲染，只启用 HTML，并移除 style 标签和属性；补充正文内列表编号、图片宽度、表格与链接的局部样式。没有修改课程价格或购买流程。
