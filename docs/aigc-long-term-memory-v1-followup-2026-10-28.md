# 长期记忆 V1 后续验证记录（2026-10-28）

结论：代码有针对性改进，隔离环境验收通过，但暂不适合向学员小范围试用。模型语义误记、调用边界、告知与实际环境配置仍需闭环。本记录不代表部署或开放。

## 网络边界

代码中网关 `/ais/**` 经服务发现转发到 `aigc-service`；学习服务的 `BotReplyClient` 也经服务发现调用其 `/chat/reply`。本次只读查询本地 Nacos 的 `tianji-local-boot3` / `DEFAULT_GROUP`，看到健康注册实例分别为 AIGC `127.0.0.1:8096`、网关 `127.0.0.1:10010`、学习服务 `127.0.0.1:8090`。这是一个命名空间的瞬时结果，不能排除其他配置来源、异机、容器、手动直连或其他命名空间。

本次系统连接快照中 AIGC 监听 `0.0.0.0:8096` 和 `[::]:8096`。其进程使用 `C:\Users\your-user\.jdks\ms-17.0.15\bin\java.exe`，本机存在匹配该程序的 Public 入站 TCP 放行规则，地址及端口均为 Any。是否适用于当前活动配置及远端实际可达性未验证。不能以单次无远端连接证明只有本机调用；没有修改防火墙、监听或注册。

建议先清点所有命名空间、部署配置、调用日志、主机和容器网络，并由网关和学习服务负责人确认调用者及地址；在独立环境从允许和禁止的来源分别验证连通性及身份头伪造。若确认均同机，评估绑定 loopback 并核对注册及容器路径；若存在异机或容器调用，保留必要监听，采用网络策略仅允许经核实的网关和学习服务来源，并增加服务间身份验证，不能依靠 `user-info` 或来源 IP 作为公网认证。验证服务发现、学习回复、网关访问及回滚后再由负责人决定上线方式。
