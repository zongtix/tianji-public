## 冒烟发现及修复

第一条真实冒烟使用自然问题“Java程序员的前端课程适合什么基础的人？”，被原模型路由分到无课程工具的知识分支，回答错误声称没有课程查询能力。这是此前固定问题集中未覆盖的路由入口问题；原失败记录保留在 `target/mcp-pilot/smoke-answer-before-routing-fix.txt`，该失败测试会话经归属与问题核对后已删除。

修复落在既有 `AgentDispatcher`：含课程指向、符合支持的纯事实维度且不属于找新课程的请求，确定进入 CONSULT。用户原话不做改写；普通推荐仍由原路由处理，绑定知识库的会话仍在该规则之前按授权范围进入知识库。事实识别与现有 `CourseFactAnswer` 共用规则，没有增加智能体或修改 MCP 契约。

相关 Java 回归 **141 项执行、141 项通过、0 跳过**，包含新增明确课程事实路由、普通找课保持推荐、知识库课程问句不越界的用例。日志为 `target/mcp-pilot/routing-fix.log`。

随后用**完全相同的原问题**真实复验成功：实际 MCP 详情读取 1 次，正文逐字匹配当前课程适用人群，卡片价格/有效期与业务资料一致，历史保存正确。该轮共有 4 次真实模型 HTTP 请求，正文由程序生成。成功记录为 `target/mcp-pilot/smoke-answer-after-routing-fix.txt` 和 `verification.json`；成功示例会话保留供续接。
