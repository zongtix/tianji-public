# 课程详情 MCP 浏览器试点验收

2026-10-27。本轮将独立命令行试点接入现有 Vue 聊天页面，保留原两门课程、DeepSeek 目的地和服务端范围守卫。页面使用独立测试身份，没有切换日常 AIGC 配置或部署公网前端。

## 使用

在仓库根目录运行：

```powershell
./scripts/mcp-pilot/pilot.ps1 -Action Start
./scripts/mcp-pilot/pilot.ps1 -Action Web
./scripts/mcp-pilot/pilot.ps1 -Action Check
# http://127.0.0.1:18084/#/assistant/index?pilot=mcp
./scripts/mcp-pilot/pilot.ps1 -Action Stop
```

网页保持现有助手的布局、Markdown、课程卡片、会话管理和停止行为，仅加入“课程资料试点”范围提示和开关。退出时整页重载，防止身份/后端切换时保留当前请求或试点视图；重新进入可恢复独立历史。日常模式仍依赖原登录与日常网关，本轮未启动日常服务。

直接改地址、浏览器返回或站内跳转导致模式变化时，在路由提交后重载；重载前助手 API 拒绝发出旧模式请求。已用真实浏览器验证直接改地址退出/重新进入，退出阶段试点接口请求和历史条目均为 0。中间的导航保护曾未通过，失败记录保留；最终通过记录为 `output/playwright/route-boundary-release.txt`。

`Web` 只在显式开发实例启用，绑定回环地址；普通开发和生产构建不能靠 `?pilot=mcp` 开启。浏览器请求不带日常 Token/Cookie，代理固定注入测试身份，只允许既有聊天及会话接口，拒绝知识库参数、内部回复、音频、自动模型建议问题以及其他 Host/Origin。模型及 MCP 服务凭据留在后端进程中。

## 浏览器验证

使用真实 Chromium 和实际后端，未拦截或伪造问答响应：

- 前端课首轮原文和价格卡片成功渲染；同会话 JavaScript 追问引用正确目录，并保留无法确认深度/完整覆盖的提示。
- 刷新后两轮正文与卡片恢复；持久化历史通过服务端 API 再核对。
- 实际点击停止按钮，出现“已停止生成”，停止后不追加课程卡片，已收到的正文保留。该用例验证页面停止行为，不宣称一定停止在 MCP 等待阶段。
- 仅停止已记录、归属校验通过的 MCP Server 后，再从页面询问微服务课前置条件。页面显示“课程详情查询暂不可用，请稍后重试。”，正文/卡片均为零，生成状态结束。第一次故障准备因沙箱拒绝停止进程而未成立，保留为 `unavailable-before-controlled-stop.txt`；随后确认端口关闭才执行有效故障验收，没有把准备失败记为通过。
- 点击退出：试点开关变为关闭、试点历史清空，该阶段试点 API 请求数为 0；重新开启后独立历史恢复。
- 完整恢复且最终路由保护生效后，再次从页面发起真实问答，核对原文、卡片、历史与实际 MCP 读取 1 次；当前运行目录该轮真实模型 HTTP 请求为 4 次。浏览器网络检查确认未带日常授权或 Cookie，没有页面 JavaScript 异常。

证据位于 `output/playwright/`：页面截图、`stop-and-history.txt`、`unavailable.txt`、`switch.txt`、`recovery-release.txt`、`route-boundary-release.txt`。API 快照及清理记录位于 `target/mcp-pilot/browser-histories.json` 和 `browser-cleanup.json`。只删除明确归属且问题匹配的三个停止/故障准备/故障测试会话，以及一个重复的旧恢复示例，保留成功的两轮示例和最新恢复问答供试用。

最终汇总为 `target/mcp-pilot/browser-verification.json`：四条自然问法及最终页面真实问答均通过；范围阻断和网关凭据泄漏计数均为 0。对 110 个文本证据文件、2 个已配置模型凭据值定向扫描，0 命中、0 读取错误。此扫描不代表对所有未知秘密的通用检测。
