# 课程事实回答的真实 MCP 验收

记录日期：2026-10-27。测试批次于北京时间 2026-10-26 23:57 完成，证据目录保留启动时的日期。

**结论：原两门课程范围内，本批 6 条真实功能验收通过，可进入独立试点。** 已验证实际模型路由与工具准备、实际课程/搜索接口、实际 MCP 详情读取以及确定性事实正文。日常详情来源未切换，MCP 默认配置仍关闭。

## 范围与通过标准

用户明确批准新的六条回答：基础咨询、两课适用条件比较、JavaScript 深度询问，local/MCP 各一次。发送目的地仅为现有 `https://api.deepseek.com`，实际模型为 `deepseek-flash`；资料限定《Java程序员的前端课程》《可能是史上最全的微服务技术栈课程》。

两个 AIGC 实例使用同一最新 JAR，测试前核实 JAR 中事实回答类与已通过本地测试的类一致。两侧只改变单详情来源，候选过滤和发送前检查同时启用。知识库、语义检索、索引同步和音频关闭，临时实例不注册 Nacos。

本批按功能验收：详情、比较必须实际取得指定详情，MCP 侧须有对应 `tools/call`；深度问题如走本地批量路径只能记为内容验证，不算 MCP 覆盖；正文、卡片和历史须符合实际资料。路由/工具集合差异作为诊断记录，不用于性能或因果比较。该模式在运行前定义于 `live-run.py --fact-answers`，原模型对照模式保留。

## 实际结果

| 场景 | local 的 MCP 读取 | MCP 分支的读取 | 正文与历史 |
| --- | --- | --- | --- |
| 基础咨询 | 0 | 1 | 两侧完整复述当前适用人群，未附加价格、目录说明 |
| 两课适用条件比较 | 0 | 2 | 两侧保留 Java 基础、SpringBoot、MyBatis 和熟练程度，无弱化的匹配收尾 |
| JavaScript 深度 | 0 | 1 | 两侧引用对应目录标题，明确仅凭目录无法确认深度或完整覆盖 |

- 六条正文分别与**本批新读取的课程快照**经当前程序生成的答案逐字一致；三组 local/MCP 正文相同。
- 六条均正常返回 SSE，且各有一个 STOP。所有可见卡片的名称、价格、有效期与当前业务接口一致；历史中的正文、卡片与客户端可见结果一致。卡片模型理由已清除。
- 实际 MCP 详情读取 **4 次**，另有一次初始化、初始化通知和发现。观测中 6 个 MCP span 均已结束，4 个为 `mcp.call`，父链均追溯到相应 `chat.request`。
- 本批六条回答共发起 **30 次实际模型 HTTP 请求**，包含路由、工具准备和标题。最终事实正文对应的模型请求为 **0 次**。路由和标题仍有流式请求，不能把所有流式请求都误认为最终正文改写；按阶段核对的证据在 `audit.json`。
- 深度问题两侧实际路由不同：local 为 RECOMMEND，MCP 实例为 CONSULT，工具集合因此不同，但正文仍一致。本批不据此宣称 MCP 提升准确率、速度或降低 Token。

## 范围与清理

- 独立检查所有实际外发工具结果，仅出现两门批准课程的 ID；越界请求阻断数为 0。候选代理共过滤 27 条候选记录，包含预检及重复查询，不是 27 门独立课程。
- 六个专用会话均已删除，最终专用用户会话总数为 0；两门课程前后快照一致。
- 本批自建的课程、搜索、两个 AIGC、MCP Server 和验收代理进程全部关闭；测试端口均已释放。Nacos 中未出现这些临时实例。
- 停止后检查 30 个文本证据文件，对照 2 个已配置模型凭据值，0 命中、0 读取错误；代理内置凭据泄漏计数为 0。
- 本轮未部署、未推送、未修改 Nacos 提示词或日常 MCP 来源配置。此前的范围失误与失败记录保留，本批未出现同类越界。

## 证据及边界

目录：`target/mcp-evaluation/mcp-fact-live-20261026/`。

- `summary.json`：最终通过状态、调用数、端口和清理结果。
- `acceptance-report.json`：六条 SSE、历史、卡片、实时快照及检查结果。
- `answers.md`：六条真实可见回答；`expected-answers.json`：按本批实时快照生成的独立对照。
- `model-calls.jsonl`、`mcp-starts.jsonl`、`mcp-calls.jsonl`、`spans.jsonl`：实际请求、结果及观测。
- `audit.json`、`trace-check.json`、`credential-scan.json`、`ports-after-cleanup.json`：正文、范围、观测、凭据和清理核对。

这是两门课程、三个固定问题各一组的功能验收，不是全平台、所有问法、稳定性、容量、浏览器或网关验收；本批也未重跑原故障矩阵或向真实 Langfuse 后端重放观测。课程/搜索的通用 `/actuator/health` 当次返回 HTTP 500，本轮依赖按实际课程与搜索读接口验证成功，未将通用健康检查记为通过。
