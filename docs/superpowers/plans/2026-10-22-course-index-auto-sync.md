# 课程向量索引自动同步

用户已同意：从逐门导入升级为首次批量扫描、发布变更自动同步、下架/删除/到期禁用、失败重试与定期核对。保留现有检索模型、维度、阈值和推荐前的业务复核。

## 设计

1. 课程服务新增内部只读快照接口：按 ID 查询或按主键游标分页，返回正式课程名称、介绍、适用人群、正文、发布状态、购买时间和删除标记。分页包含软删除记录，以便漏掉删除事件后仍能禁用旧向量。草稿不会进入索引。
2. AIGC 使用独立持久化队列消费既有 `course.up/down/expire/delete` 事件，消息只携带 ID；消费时重读正式快照。上架/重新发布及下架事件调整为事务提交后发送，回滚不发；发送失败记录并交给核对扫描补齐。
3. 共用原有正文归一化与内容摘要算法。有效且正文未变时跳过 Embedding；更新时以 ES 文档版本条件覆盖原文档，防止并发消费覆盖较新的结果。新文档使用稳定 ID，已有试点文档沿用原 ID。
4. 不可用、已删除或正文为空的课程写为禁用记录，移除向量，`documentType` 不再为 `course`。禁用也保留 ES 版本，因此旧的在途创建请求不能越过禁用记录重新生效。读 ES 版本先于读取课程快照，冲突后必须重新读取全部状态。
5. 启用后后台定时按 ID 每批扫描（默认 50 条），第一次循环完成全量初始化，之后循环补齐漏事件和购买时间变化。单门失败不阻塞后续课程。每次同步有限重试，耗尽后进入独立失败队列；周期核对继续修复。
6. 自动同步默认关闭，只有 ES 课程检索及显式同步开关均启用时建立监听和定时任务。验证用隔离索引和测试消息，不对正式课程做上架、下架或内容改写，不顺带部署 Audio/Bot 工作。
