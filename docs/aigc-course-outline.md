# 课程目录参与语义检索与回答（2026-10-23）

## 改动

课程内部详情 `/course/{id}/baseInfo` 和索引快照 `/course/semantic-index`、`/course/semantic-index/{id}` 新增 `catalogue` 字符串列表。只读取 `course_catalogue` 中正式、未删除的章与小节，不查询草稿、练习、媒资、教师或考试服务。章与小节保留父子关系，例如 `认识微服务 / 微服务架构演变`。

目录按章序号、章 ID、类型、小节序号和小节 ID 稳定排序；已删除章下面的小节、孤立小节、跨课程关联和空标题不作为证据。分页快照批量读取本页所有课程的目录，不逐门增加目录 SQL。没有有效目录时返回空列表；旧接口未提供该字段时，AI 不把缺失解释为课程一定不包含某项内容。

手工导入从正式数据库读取同一批章节，自动同步从课程快照获取目录，二者继续复用 `CourseDocumentService.toDocument`。有目录时追加 `正式章节目录（仅标题）` 并记录 `course_catalogue` 来源；目录参与正文摘要，改名、删除或调整顺序会改变版本。没有目录的课程保留原正文格式和摘要。名称、介绍或详情的原有必填规则不变，只有目录也不会被当作完整课程资料。

推荐和咨询工具的 `CourseInfo.catalogue` 来自本轮课程服务详情，不使用向量快照中的旧目录回答。价格、状态、购买时间与有效期仍按既有流程读取业务接口；候选归属、卡片协议、知识库隔离及 0.6 检索阈值不变。

推荐和咨询提示词新增资料边界：区分介绍声明与目录标题；目录不证明讲解深度、完整覆盖或学习效果；目标人群不能推导为课程深度限制；宣传标题不能作为技术覆盖证据；匹配已列出的前置条件不代表不需要任何其他基础。冲突与缺失均如实说明。

## 已有索引如何更新

新增目录会改变已有正文摘要，旧手工导入器仍会拒绝直接覆盖不同版本；不要删除原文档再重导，也不要把拒绝覆盖视为目录改动没有生效。

按 [自动同步说明](aigc-course-index-sync.md)，先发布包含目录字段的课程服务，再发布 AIGC。启用索引同步后，巡检或课程变更通知通过既有版本条件更新原记录，沿用原 ES ID。关闭同步时，已存在的向量不会因为代码更新自动重算。更新会调用配置的 Embedding 服务，课程目录属于发送的正文之一，需在实际启用范围内安排。

这次只验证独立端口和临时索引，不自动开启日常全课程巡检。工作区其他 Audio/Bot 改动的部署验收另行处理。

- 两门课程在只读 SQL、内部详情和索引快照返回的正式目录完全一致。
- 保留原失败问题 `熟练 Spring Boot/MyBatis，学习微服务架构演变与 Spring Cloud`：补目录前无候选；补目录后命中原有微服务课，返回分数约 `0.6060252`。仍使用原模型、1024 维、top-k 5 和阈值 0.6，没有替换问题或下调阈值。分数接近阈值，只证明这个样本改善，不能推断所有微服务问法都能稳定命中。
- 两门目录更新后重复同步返回 `UNCHANGED`，临时索引文档数量不变。
- 首轮真实对话 6 轮、32 项自动检查通过，覆盖微服务推荐及目录依据、价格与起算规则追问、后端补前端、前端深度与 Vue/React 目录证据、未说明的答疑/证书/就业保证，以及未使用 Spring Boot/MyBatis 的适配判断。
