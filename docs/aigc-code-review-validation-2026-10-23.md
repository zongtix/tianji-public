## 复现 AIGC 回归（PowerShell，JDK 17）

```powershell
$env:JAVA_HOME = 'D:\Java\jdk-17'
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
$reviewTests = (Get-ChildItem -LiteralPath 'tj-aigc/src/test/java' -Recurse -Filter '*Test.java' | Where-Object BaseName -ne 'AigcContractTest' | ForEach-Object { $_.BaseName } | Sort-Object -Unique) -join ','
mvn -pl tj-aigc -am "-Dtest=$reviewTests" '-Dsurefire.failIfNoSpecifiedTests=false' test
```

本轮相对于修改前工作区的差异保存在 task-changes.patch，不包含此前已有的改动。
